# № 10 Блокчейн

Заявка: работа на открытых данных блокчейна. Чувство: напряжение и разрядка. Десять топовых сетей, кнопка переключает сеть.
Источник: mempool.space, litecoinspace.org, PublicNode (Эфириум, BNB, Avalanche, Solana, Tron), TronGrid, xrplcluster.com, Koios, Blockchair. Ключи не нужны. Всё идёт через маршруты Vite: из браузера в России часть хостов зависает, с сервера те же адреса отвечают за доли секунды. Из России без прокси проверено 2026-11-06, ответили все десять сетей.
Концепция: лист копит заряд цветом сети, настоящий новый блок забирает всё разом. Вариант выбирает автор.

| Величина | Канал | Почему |
|---|---|---|
| Сеть | Цвет | Сразу видно, какая сеть на листе |
| Транзакции, ждущие блока | Точка | Счётное показано счётным |
| Время с прошлого блока | Заполнение листа | Напряжение растёт со скоростью сети |
| Новый блок | Разрядка | Её вызывает только настоящее событие сети |

Условности: скорость заряда оценена по прошлым блокам, а не взята из мемпула. Быстрые сети разряжаются раз в несколько блоков, иначе лист стал бы стробоскопом. У Solana транзакции на блок взяты из минутной сводки. У сетей с большими блоками точка значит несколько транзакций.
