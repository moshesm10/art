# Студия Пульса

Как идея становится работой. Один выпуск — одна страница `/work/<slug>/`. Главная пока служит мастерской: работы разделены на готовые к публикации и идеи.

## Как прислать идею

Хватит одной строки:

```
/new-work землетрясения как музыка
```

Можно приложить API, картинку, файл или ссылку. Полная заявка, все поля необязательны:

```
/new-work
Идея: о чём работа
Источник: API, ссылка или файл
Ощущение: что зритель почувствует за три секунды
Референс: картинка, настроение, автор
Случайно: что меняет кнопка
Нельзя: чего точно не хочется
```

Написал «делай» — Claude не задаёт вопросов и решает сам.

## Цикл выпуска

| День | Что происходит | Твоё участие |
|---|---|---|
| 0 | Заявка, проверка источника, три концепции | Выбрать одну, пара минут |
| 1 | Кодировка, сборка, тесты, проверка | Нет |
| 2 | Показ живых вариантов, правки, выпуск | Выбрать вариант или поправить |

Если есть интересные идеи, работа приходит сразу в нескольких живых вариантах: `/work/<slug>/?look=a`, `?look=b`. Выбранный остаётся, остальные удаляются.

Нет идей — бери строку из `releases/backlog.md`.

## Устройство

| Что | Где |
|---|---|
| Реестр выпусков: номер, адрес, дата | `src/works.ts` |
| Статусы работ, их меняет кнопка в мастерской | `src/works-stages.json` |
| Код работы | `src/channels/<slug>.ts` |
| Страница работы и каталог | `src/pages/` |
| Киоск для iPad: показ готовых работ по кругу | `src/pages/kiosk.ts`, адрес `/kiosk/` |
| Источники `/api`: прокси Vite и прямые адреса сборки | `src/routes.ts` |
| Замены для iOS 12 и прямые запросы в сборке | `src/lib/legacy.ts` |
| Список камер Окна для сборки | `scripts/cams.mjs`, `public/cams.json` |
| Контракт постера и печать | `src/lib/poster.ts` |
| Сеть: опрос, сокеты, поток | `src/lib/net.ts` |
| Языки: определение, переводы `tr(ru, en)`, локаль | `src/lib/i18n.ts` |
| Города и горы с названиями на двух языках | `src/data/` |
| Маршруты к источникам без CORS | `vite.config.ts` |
| Контрактный тест всех работ | `tests/works.test.ts` |
| Съёмка и проверка страницы | `scripts/shot.mjs` |
| Превью для каталога | `public/previews/<slug>.jpg` |
| Папка выпуска | `releases/<slug>/` |
| Пайплайн и шаблон | `.claude/skills/new-work/` |

Все тексты работы пишутся сразу на двух языках через `tr('…', '…')`, у мест есть поле `en`. Если работа знает координаты показанного места, она отдаёт их в `where()`, и страница покажет миниатюру карты.

Работа реализует интерфейс `Poster`: лист 100 × 140 единиц, область рисунка `ART`, подпись и зерно печатает оболочка. Страница грузит только код и источники своей работы, поэтому число выпусков не замедляет ни одну страницу.

Работа на архивных данных тоже держит `Feed`: `new Feed('Архив', Infinity)`, и `feed.ok()` при старте.

## Бриф выпуска

Файл `releases/<slug>/brief.md`:

```markdown
# № N Название

Заявка: как её прислал автор.
Источник: адрес, лимит, лицензия, дата проверки из России.
Концепция: выбранная и почему.

| Величина | Канал | Почему |
|---|---|---|

Условности: что на постере не буквально.
```

## Публикация

`npm run cams && npm run build` собирает в `dist/` статичный сайт: его можно положить на любой хостинг в корень домена, сервер не нужен. В сборку входят только готовые работы, браузер идёт к их источникам напрямую. Ключ Windy остаётся на компьютере: `npm run cams` запекает список камер, поэтому перед выпуском его стоит обновлять.

Работе, которая становится готовой, нужен источник с CORS, иначе на сайте она не получит данных. Проверяй это без прокси.

Киоск собран под iOS 12: новый метод браузера в готовой работе нужно проверить и при необходимости добавить в `src/lib/legacy.ts`.
