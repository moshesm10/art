# Пульс

Серия живых постеров. Каждая работа — отдельная страница `/work/<slug>/`: реальные данные становятся цветом, формой и скоростью. На плакате почти нет цифр, вся информация в самой композиции. Главная пока служит мастерской: работы разделены на готовые к публикации и идеи, статус меняется кнопкой на карточке и работает только с `npm run dev`. Как делается новая работа, описано в [docs/studio.md](docs/studio.md).

Все источники бесплатные и работают без ключей.

## Запуск

```sh
npm install
npm run dev
```

Откройте http://localhost:5173. Для киоска: http://localhost:5173/work/markets/?tour, браузер лучше запускать в режиме киоска: при переходе между страницами полноэкранный режим сбрасывается.

`npm test` запускает тесты, `npm run build` проверяет типы и собирает проект, `npm run shot -- <slug>` проверяет страницу работы и снимает превью.

## Управление

| Клавиша | Где | Действие |
|---|---|---|
| `1`–`9` | Мастерская | Открыть работу |
| `←` `→` | Работа | Предыдущая и следующая работа |
| `R` | Мастерская | Случайная работа |
| `R` | Работа | Новый выбор внутри вида данных |
| `A` | Везде | Тур по работам |
| `F` | Работа | Полноэкранный режим |
| `Esc` | Работа | Назад в мастерскую |

Значок внизу постера показывает связь: полный круг — данные идут, кольцо — ждём, перечёркнутый — связи нет или данные устарели. При наведении на элемент постера видно, какие данные за ним стоят.

## Настройка

Города, аэропорты, монеты, лиги и точки наблюдения лежат в `src/config.ts`. Постер — это класс в `src/channels/`, реестр выпусков в `src/works.ts`, общий контракт и печать в `src/lib/poster.ts`. Постер рисует на листе 100 × 140 единиц, разрешение подбирает оболочка.

## Сеть

REST-запросы к adsb.lol, OKX, ESPN, MET Norway и Open-Meteo идут через сервер Vite (`vite.config.ts`), поэтому стенду нужен `npm run dev` или `npm run preview`: простая раздача папки `dist` не подойдёт. Если задан `HTTPS_PROXY`, сервер ходит через него.

Поставщики выбраны так, чтобы работать из России без VPN. Проверять доступность нужно без прокси и по полному телу ответа: `api.open-meteo.com` из России не отвечает, а Gate.io отвечает кодом 200, но обрывает большие ответы на 12–20 КБ. Качество воздуха остаётся у Open-Meteo: его отдельный адрес из России доступен, и если он пропадёт, постер просто покажет солнце без колец.

Текст постов Bluesky не хранится и не выводится: поток не модерируется, поэтому на публичном экране показываются только агрегаты.
